# Changelog

All notable changes are documented in this file. The project follows semantic versioning.

## 1.0.0 - 2026-08-11

### Added

- Protocol-aware Ethernet II, VLAN, IPv4, UDP, and TCP checksum inspection.
- Incremental one's-complement arithmetic and IPv4 pseudo-header seed helpers.
- Independent ready/valid cycle model, deterministic campaign, and versioned RTL vectors.
- Synthesizable 64-bit streaming checksum RTL with simulation, synthesis, and bounded formal evidence.
- Strict bounded JSONL input, deterministic JSON and Markdown reports, and atomic report writes.
- Four-command CLI, isolated wheel and source-distribution checks, and Python 3.10-3.14 CI.

### Evidence boundary

This release does not claim physical timing closure, device-specific line rate, production deployment, IPv6 support, fragment reassembly, or checksum insertion.
